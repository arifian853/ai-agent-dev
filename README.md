# Arifian — Portfolio Landing Page
> **Soft Editorial Materialism • Subtle Design System (Rosewood Mood)**

A pure semantic HTML5, CSS3, and modern vanilla JavaScript portfolio website built for **Arifian** (Senior Product Designer & Design Systems Architect).

---

## 🎨 Design Specification & Mood
- **Design System:** Subtle Design System ([DESIGN.md](DESIGN.md))
- **Primary Direction:** Soft Editorial Materialism
- **Active Mood:** **Rosewood**
  - `--bg-main: #FAF5F5`
  - `--bg-surface: #FFFFFF`
  - `--bg-surface-variant: #F3E9E9`
  - `--primary: #7A4F55`
  - `--primary-container: #EEDCDD`
  - `--border-subtle: #E7DADA`
  - WCAG 2.2 AA compliant contrast
- **Typography:**
  - *Lexend Deca* (Headings & Display typography)
  - *Inclusive Sans* (Body copy, UI controls, navigation)
  - *JetBrains Mono* (Code, metadata, system tokens)

---

## 🚀 Key Features

1. **Tonal Hero Section**
   - Fluid typography with responsive `clamp()` scale
   - Context capsule & live availability status
   - Signature artboard preview showcasing the Rosewood token palette

2. **Soft Mosaic Bento Cards (Craft & Capabilities)**
   - **Interactive Live Token Inspector:** Live slider to test corner radius tokens (`--radius-sm` to `--radius-xl`) and surface tone switching in realtime
   - **Product Ergonomics:** Human-computer interaction principles and structured feature breakdown
   - **Tool Stack:** Core production tools (Figma, HTML5/CSS3, JavaScript, Git)
   - **Research & System Adoption:** 94% component adoption telemetry metric

3. **Career Trajectory & Experiences**
   - Narrative timeline spanning 8+ years across enterprise cloud consoles, venture design consultancies, and digital agencies

4. **Education & Credentials**
   - Computer Science & HCI background (University of Indonesia, Cum Laude)
   - Certified Web Accessibility Specialist (*W3Cx WCAG 2.2 AA*)
   - Design Systems Leadership credential

5. **Selected Works & Interactive Case Studies**
   - Filterable projects (*All*, *Design Systems*, *Product UX*, *Editorial*)
   - Accessible modal drawer dialog (`<dialog>`) with full keyboard navigation and deep dive case study breakdowns

6. **Soft Command Bar (`Ctrl+K` / `Cmd+K`)**
   - Quick search palette for jumping to sections, copying contact information, and launching interactive demos

7. **Zero-Dependency Architecture**
   - 100% hand-crafted vanilla HTML, CSS, and JS with zero framework runtime overhead
   - Full reduced motion compliance via `@media (prefers-reduced-motion: reduce)`
